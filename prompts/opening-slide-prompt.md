# Opening Slide Image Generation Prompt

## For Gemini Imagen (Static + Video)

```
Create a cinematic, high-tech military intelligence operations center opening scene with NO TEXT. 

COMPOSITION:
- Wide-angle establishing shot of a futuristic command center
- Multiple holographic displays and screens floating in 3D space
- Dark, moody lighting with blue and amber accent lights
- Depth of field with layers of information at different depths

INTELLIGENCE ELEMENTS TO INCLUDE:
1. Surveillance Drones - Multiple UAV silhouettes at different altitudes, some with targeting reticles, shown as holographic projections or on tactical displays
2. RF Intelligence - Animated radio wave patterns, signal intercepts visualization, electromagnetic spectrum displays with frequency bands
3. VISINT (Visual Intelligence) - Satellite imagery feeds, reconnaissance photo streams, optical camera feeds showing terrain and structures
4. Collection Systems - Sensor arrays, antenna farms, ground stations with parabolic dishes, mobile collection vehicles
5. Software/Tech Infrastructure - Flowing data streams, code matrices, network topology maps, AI processing nodes
6. Reconnaissance Assets - Tactical maps with movement vectors, patrol routes, coverage zones highlighted
7. Target Indicators - Geographic markers, heat signatures, building layouts, trajectory predictions (subtle, not aggressive)

VISUAL STYLE:
- Cinematic color grading: deep blacks, rich teals, warm amber highlights
- Volumetric lighting with god rays through holographic displays
- Particle effects: data streams, light particles, subtle atmosphere
- Semi-transparent interfaces with technical readouts (no readable text, just visual texture)
- Military-grade aesthetics: precise, professional, high-tech but realistic
- Depth layers: foreground displays, mid-ground workstations, background wall screens

MOOD & ATMOSPHERE:
- Professional and authoritative
- High-tech but not sci-fi fantasy
- Focused, operational readiness
- Intelligence gathering in progress
- Command and control environment
- Subtle motion blur to suggest this is a moment captured from ongoing operations

TECHNICAL SPECS FOR VIDEO:
- Composition should support camera movement (slow push-in or parallax)
- Elements at multiple depth planes
- Ambient animation potential (screens updating, data flowing)
- 16:9 aspect ratio
- High dynamic range suitable for screen display
- Clean silhouettes that work in motion

Remember: ABSOLUTELY NO TEXT, NUMBERS, or READABLE WORDS. All screens and displays should show abstract data visualization patterns, waveforms, maps, and graphical elements only.
```

## Alternative Shorter Prompt (if the above is too long):

```
Cinematic military intelligence command center, no text. Show: surveillance drones on holographic displays, RF signal intelligence waveforms, satellite imagery feeds, sensor collection systems, data streams, reconnaissance maps with target markers, tactical screens. Dark moody lighting, blue and amber accents, volumetric atmosphere, multiple depth layers, high-tech professional aesthetic. Wide establishing shot, 16:9, suitable for both static and animated video. Make it look like a live intelligence operation in progress.
```

## Tips for Video Generation:
- Request slow camera movement (dolly forward or gentle parallax)
- Ask for subtle screen animations and data flow
- Suggest particle effects and ambient motion
- Specify smooth transitions suitable for looping
- Mention 4-6 second duration minimum for presentation use
