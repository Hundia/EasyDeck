# Proposal: Sprint 0 — Foundation & Scaffolding

## Change ID
`sprint-0-foundation`

## Why
Before any implementation can begin, the project needs proper infrastructure:
- Documentation hierarchy for developer reference
- OpenSpec configuration for spec-driven development
- Sprint execution tooling (skills, backlog)
- Agent orchestration configuration

## What Changes
- Created `/docs/` hierarchy with architecture, components, schemas, accessibility, integration, and development guides
- Created `/spec/` directory structure for OpenSpec workflow
- Created `CLAUDE.md` with project rules and context
- Created `AGENTS.md` with orchestration configuration
- Created `backlog.md` with full sprint plan (9 sprints)
- Created `/run-sprint` skill for sprint execution
- Created `.openspec/config.md` for spec configuration

## Impact
- **New files**: ~30 documentation and configuration files
- **Affected specs**: All (this establishes the spec structure)
- **Code changes**: None (infrastructure only)
